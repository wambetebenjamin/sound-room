# Sunday set — three long arrangements

Everything here is generated by `scripts/build_worship_set.py`. No samples, no loops,
no third-party audio. Key, tempo and chord loop come from the worship chord charts;
the voices, timing and mix are ours.

| # | Track | Key | Tempo | Length | Chord loop |
| --- | --- | --- | --- | --- | --- |
| 1 | Goodness of God | Ab | 63 | 3:18 | D♭–A♭–D♭–A♭ |
| 2 | Amazing Grace (Graveson) | Eb | 72 | 2:53 | E♭–E♭/G–A♭–A° |
| 3 | This Is Amazing Grace | G | 98 | 2:07 | G–C–Em–D |
| — | **Complete set** | — | — | **8:16** | crossfaded 1.5 s |

The arc is deliberate: intimate 63 BPM → gathering 72 → celebration 98.

## Song form (each track, 52 bars)

`intro 4 · verse 8 · chorus 8 · verse 8 · chorus 8 · bridge 4 · chorus 8 · outro 4`

Each section restarts the chord loop on its own tonic. The final chorus carries 1.12×
energy, the bridge builds from 0.85×, so the set has a **9.9 dB dynamic range** instead
of sitting flat like a loop.

## The bass line

The bass is not a repeated root — it walks into every chord change:

| Section | Line |
| --- | --- |
| Intro | root, then the fifth |
| Verse | root · root · fifth · **chromatic approach** to the next root |
| Chorus | root · root · fifth · **octave** · fifth · approach |
| Bridge | root · **third** · fifth · **octave** · approach |
| Last bar of a section | run up root → third → fifth → octave |

The approach note is a semitone below (or above) the next chord's root, so the harmony
is always being led somewhere. Measured on the loop: **14 distinct bass pitches** where
the old line had 1.

## Master
Complete set: **−14.2 LUFS · −1.15 dBTP**. Splice points measured at −26.7 dB and
−27.0 dB local sample jump, so the crossfades are clean (no clicks). Dynamic range
7.5 dB across the set.

## Regenerate
```bash
python3 scripts/build_worship_set.py                 # full render, ~3 min
python3 scripts/build_worship_set.py --reuse         # rejoin existing tracks, ~15 s
python3 scripts/build_worship_set.py --chart "Oceans (Where Feet May Fail).onsong" --tempo 0=68
```
Charts usually do not carry a tempo — 577 of the 613 parseable ones default to 72 BPM —
so tempos are set explicitly in the `SET` table at the top of the script.
